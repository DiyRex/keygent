# Diagrams

Excalidraw sources, generated by `build.py` (deterministic). **Edit the script and re-run it**, so diagrams don't drift from the spec:

```sh
python3 docs/diagrams/build.py
```

Open with https://excalidraw.com (File → Open) or the VS Code "Excalidraw" extension.

| File | Shows |
|---|---|
| `01-system-architecture.excalidraw` | Components, trust zones, where plaintext exists |
| `02-trust-boundaries.excalidraw` | Attacker tiers T1–T3, what a same-user agent can and cannot do |
| `03-run-sequence.excalidraw` | `keygent run` with the default `approve` policy (broker-observed approval), end to end |
| `04-key-hierarchy.excalidraw` | Unlock factors → KEK slots → DEK → HKDF subkeys, `vault.kgt` layout |
| `05-unseal-and-auth.excalidraw` | Unseal handoff over an inherited pipe, anti-squat, mutual re-auth |
| `06-web-console-passkey.excalidraw` | Passkey login and per-action confirmation |
| `07-platform-matrix.excalidraw` | Linux / macOS / Windows primitives behind the `Platform` trait |
| `08-release-pipeline.excalidraw` | Release-only pipeline, signing and provenance |
| `09-hook-composition.excalidraw` | Why other tools' hooks are chained behind keygent (parallel hooks vs chain composer) |
